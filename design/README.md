# 研序 QUANT · 量化研究系统设计原型

直接打开 `quant-system-design.html` 即可查看，无需安装依赖、联网或启动后端。

本地预览：`node design/serve.cjs`，地址 http://127.0.0.1:8765 。如果已在运行，无需重复启动。

## 页面与研究链路

研究工作台 → 数据中心 → 因子计算 → 因子资产库 → 因子筛选 → 样本与标签 → 模型实验室 → 策略构建 → 回测与归因 → 模拟跟踪。

量化工作区现以六阶段贯通页面：数据准备 → 因子研究（计算 / 画像 / 筛选）→ 样本设计 → 信号与组合 → 回测归因 → 模拟跟踪。各环节显示承接输入、本步产物、进入下步前的检查和前后导航。模型路径经过训练、验证、注册再构建组合；因子合成路径在样本设计后直接配置合成与组合。工作台和样本 / 信号页面的路径选择与策略信号类型同步。模拟页按数据、信号、执行异常提供复核入口。导航高亮仅表示位置，不代表计算或验证通过。

另有任务中心与系统蓝图。系统蓝图包括页面地图、架构、对象主键、版本血缘、接入契约、权限、任务协议与分阶段验收。

“空间设计与接入”是两条研究路径的公共说明，独立路由为 `#workspace-design`。量化与情报侧栏都提供“公共工作区”入口；页面统一解释两条路径、共享资源、版本规则和成果交接。旧 `#intelligence/design` 链接自动跳转到公共页面。第一版情报侧栏的研究提示文案已移除。

“情报研究”已拆为并列的独立工作区，入口 http://127.0.0.1:8765/intelligence.html 。左上角可在量化研究与情报研究之间切换。原有 `#intelligence` 链接仍可使用。

情报研究闭环：事件雷达 → 专题研判 → 研究备忘录 → 持续跟踪 → 研究档案。雷达先筛选信息增量；专题围绕问题与证据组织研究；Agent 配置和观察摘要收在专题的协作核验中。报告可建立带验证条件、反证条件、复核日期的跟踪计划；复核支持记录证据、反证、归档和恢复。每个跟踪计划绑定原始报告快照。量化研究交接单可导出假设、证据、可知时间、事件窗口和基准，执行器待接入。

本模块提供三个完全虚构的案例，用于展示政策预期、供应扰动与公司澄清的不同传导路径。可配置时点与角色、回放流程、停止回放、查证据卡、查看历史报告、导出 Markdown / HTML。没有调用真实模型或抓取新闻。来源同时按发布时间与实际可知时间过滤；证据或关键角色不足时不输出完整影响判断。页面修改配置后保留旧报告快照并提示需要重新回放。

## 已有工程接入

数据中心的“现有数据接入”页提供只读适配、字段映射与批次清单设计。已有行情继续保留；因子按已完成的日期分区逐批登记和校验，无需等待全部因子计算完成。

原始数据、标准数据、因子值、样本集、模型和回测分别版本化。修改上游数据后生成新版本，旧报告仍绑定旧输入。

## 原型的交互范围

支持页面切换、全局搜索、因子搜索/分类/排序/勾选、因子详情、条件筛选演示、特征集草稿、数据集配置、模型参数切换、策略参数与权重配置、回测页签、任务与日志示例、预警配置及 JSON/CSV 导出。

状态保存在当前页面会话，刷新会重置；可通过导出配置留存。训练、计算、回测和模拟交易均为交互演示，未连接你的真实数据或计算服务。所有结果与收益均标注为固定示例，不会因为修改参数而伪造新的计算结果。参考截图中的收益、费用和投资结论不作为系统事实。

## 文件

- `quant-system-design.html`：独立单文件交付版。
- `index.html` 与 CSS/JS：可继续修改的分文件源稿。
- `intelligence.html`：情报研究独立入口；`intelligence-workspace.js / .css`：工作区导航、事件筛选、跟踪和交接；`intelligence.js`：共享的演示案例与报告引擎。
- `intelligence-design.html`：可离线打开的情报研究单文件交付版。
- `shared-workspace.js / .css`：两条研究路径共用的“空间设计与接入”页面与公共导航。
- `build.cjs`：将两个工作区分别构建为独立 HTML。
- `serve.cjs`：仅监听本机地址的预览服务。
- `preview-*.png`：页面验证截图。
- `verify.cjs`：用于当前环境的浏览器交互检查脚本。

## 验证

`node design/verify-shared-workspace.cjs` 验证两边公共入口、统一页面、往返状态保留、旧链接兼容、移动端导航和离线文件。

`node design/verify-quant-workflow.cjs` 验证六阶段的页面接续、模型 / 因子合成两条分支、信号类型同步、模拟复核回路、三种屏宽与离线入口。流程实现位于 `quant-workflow.js / .css`。

12 个页面渲染、主要页签、因子查询/详情/筛选、配置保存、模型参数切换、策略权重/勾选状态、JSON 导出、预警弹窗、390px 宽度及独立 HTML 打开已检查。没有真实后端计算测试。

`node design/verify-intelligence.cjs` 运行独立情报工作区的验收（实现在 `verify-intelligence-workspace.cjs`）：三个案例、归档恢复、信息时点与关键角色门槛、取消回放、原报告快照保留、配置变更提示、跟踪复核与证据校验、量化交接单、报告/工作区导出、五个研究视图的四种屏宽、工作区切换及两个离线交付版。此脚本的截图和导出文件保存在忽略的 `.qa/` 目录。

## 现有后端产物合并（保留原设计链条）

当前启动：`node design/serve.cjs`，地址 http://127.0.0.1:8871 。本节取代前文旧预览端口说明；8765—8769 的后端监控及旧 8870 服务不做修改。

本次以原有页面设计为底板，没有替换六阶段流程、模型/因子合成分支、模型参数表单、策略与回测布局。新增 `backend-merge.js / .css` 将产物放入所属环节，因子资产目录使用真实实体，选择结果继续传入原有筛选、特征集、样本与导出配置。

`backend-snapshot.cjs` 只读本机实际存在的 `D:/futures_quant_strategy`，读取报告、因子发布清单及采集状态。可用环境变量 `QUANT_BACKEND_ROOT` 指定其他目录。不会修改后端文件、打开 DuckDB 或调用计算任务。每 60 秒刷新；失败保留旧快照并提示。状态文件 RUNNING 不等于确认进程存活。

- 数据中心：真实基础表、审计样例及采集状态补入原有四个视图之前。
- “质量与覆盖”标签页已替换示例数字，浏览器直接请求后端 `http://127.0.0.1:8770/api/v1/quality/overview`。接口实时读取行情、参考/股票池、公司行动、财务 PIT 和因子发布五类审计。异常隔离、PIT 例外、低覆盖因子、审计批次与时间均来自后端响应；覆盖热图表示报告起止区间，不宣称逐月完整性已核验。
- 因子计算：真实发布批次与原定义工作台、依赖、分区、回填、任务布局合并。新增从后端公式载入、新公式定义草稿、已有目录计算配置、字段检查、持久化和导出。
- 因子资产库：13 个因子的 39 个变体沿用原目录交互；IC 和覆盖率取各自 basic_evidence，未提供 ICIR 则留空。真实画像显示滚动和增量证据。用途暂按“预测”用于配置，不代表正式准入。
- 因子筛选：真实簇及机械代表补充到原筛选流程；本地初筛只是已有指标过滤，不执行新的训练、去重或验证。
- 样本至模拟：保留所有原有设计、参数、交互和样例报告；增加真实研究输入说明和版本引用。原有导出配置新增 `backend_inputs`，并明确未执行。

原设计中没有真实产物的热图、任务、模型和收益仍标示为样例，不与真实证据混为一谈。2020—2025 已经是暴露研究样本，既有滚动诊断不能当成新的未见样本外验证。

当前源码确认的执行入口为 `scripts/publish_factor_release.py`（日期、initial/m4.2 整套目录）和 `publish_processed_factor_release.py`（父发布 ID、预处理变体）。未确认统一计算 HTTP 接口，因此“新增公式”和“一键计算”没有声称注册或提交成功。自定义公式 JSON 是前端交接草稿；还需后端编译依赖、生成实现哈希并注册。已有目录模式可导出与现有脚本相符的命令，但前端不执行。

验证：`node design/verify-backend-merge.cjs`（依赖 `design/.qa/node_modules/playwright` 及本机 Chrome）；覆盖原链条、模型分支、真实候选到样本的交接、导出、计算布局与草稿、桌面/移动端和断连。`node design/build.cjs` 更新离线单文件；离线模式保留原设计并明确不能读取后端。
